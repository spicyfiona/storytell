# Storytell
A web-app game to type writing what does the message of emojis mean?

# Goals
There's always a random series of emojis. Storytell wants to understand how you decipher the emoji language by writing what the random sequence of emojis mean to you.
Be as creative or simple as you like.

# Quick Start
Open this link: https://v0-storytell.vercel.app/ in any web browser (Google Chrome, Apple Safari, Firefox).
